Security

Security, as it stands today.

This page covers access, header, and data-handling controls we can point to in a public pull request or a live check run on 24 November 2026. It also says plainly what we have not finished, and what we do not claim.

Access control

Mission Control at missioncontrol.a-gent.co is invite-only. A visitor who is not signed in receives an HTTP 401 sign-in page, not the application. That page does not offer a way to create an account.

Sources: mission-control#3, mission-control#4, live check of missioncontrol.a-gent.co on 24 November 2026.

Browser and transport protections

a-gent.co, aisdr.a-gent.co, and missioncontrol.a-gent.co are served over HTTPS and send HTTP Strict Transport Security.

The marketing site, a-gent.co, also sends X-Frame-Options: DENY, X-Content-Type-Options: nosniff, and Referrer-Policy: strict-origin-when-cross-origin.

Source: live check of a-gent.co on 24 November 2026.

Mission Control also sends Content-Security-Policy: frame-ancestors 'none', X-Frame-Options: DENY, X-Content-Type-Options: nosniff, Referrer-Policy: strict-origin-when-cross-origin, Permissions-Policy, and X-Robots-Tag: noindex, nofollow. The sign-in response is served with Cache-Control: no-store, private.

Sources: mission-control#3, mission-control#4, live check of missioncontrol.a-gent.co on 24 November 2026.

On the Sales Agent host, aisdr.a-gent.co/ and /signup send Content-Security-Policy: frame-ancestors 'none', X-Frame-Options: DENY, X-Content-Type-Options: nosniff, Strict-Transport-Security with includeSubDomains, Referrer-Policy: strict-origin-when-cross-origin, Permissions-Policy, and X-Robots-Tag: noindex, nofollow. Some other public pages on that host, including /agent.html, send the same noindex, nosniff, HSTS, Referrer-Policy, and Permissions-Policy headers, but not X-Frame-Options or Content-Security-Policy.

Sources: sales-agent#5, live checks of aisdr.a-gent.co, /signup, and /agent.html on 24 November 2026.

Closed file exposures

On the live Sales Agent host, we blocked public access to internal configuration and data files. Those paths now return HTTP 404.

Source: live checks on 24 November 2026.

Public marketing site forms

The demo inquiry form on this marketing site sends a Prefer: return=minimal header so the browser does not read the inserted row back after a submit.

Source: gtm-revolution-web#1.

Data and service providers

We use the following providers to operate these sites and the product. This list is limited to providers we can show from a live hosting header or from environment variable names in the public repositories. It is not a claim that every integration is turned on in production, and it is not a complete inventory of every optional connector in the code.

  • Netlify hosts a-gent.co, aisdr.a-gent.co, and missioncontrol.a-gent.co. Live responses include a Server: Netlify header.
  • Supabase is used for authentication and database access. The Mission Control and Sales Agent repositories reference SUPABASE_URL and related variable names. This marketing site writes demo and assessment submissions there.
  • Resend is referenced in the Sales Agent codebase for email delivery, including RESEND_API_KEY and RESEND_WEBHOOK_SECRET.
  • This marketing site loads fonts from Google Fonts.

The Sales Agent repository also references environment variable names for optional product features and connectors, including OpenAI, Stripe, and HeyGen. Presence of a variable name is not a claim that the integration is enabled for every workspace.

Sources: live Server headers on 24 November 2026; environment variable names in the sales-agent, mission-control, and gtm-revolution-web repositories; sales-agent#4; gtm-revolution-web#1; gtm-revolution-web#3.

Data requests and security contact

We do not publish a data-retention schedule on this page. To request deletion of personal data, or to report a security issue, contact Mark.cope.roarr@gmail.com.

What we do not have yet

We want this page to be useful, so the gaps are listed here as well.

  • We do not have a SOC 2, ISO 27001, HIPAA, or similar certification, and we do not claim a GDPR certification.
  • We do not publish an uptime service level agreement, and we do not claim a completed third-party penetration test.
  • Database row-level security hardening is in progress and is not finished.
  • We do not yet publish terms of service or a data processing agreement. /terms and /dpa returned HTTP 404 on 24 November 2026.

Sources for the in-progress database work: mission-control#5. Sources for unpublished legal pages: live checks of a-gent.co/terms and a-gent.co/dpa on 24 November 2026.
